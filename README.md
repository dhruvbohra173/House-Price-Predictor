# 🏠 Housing Market Analytics Dashboard

An interactive **Power BI dashboard** designed to analyze Danish residential real estate sales, uncover regional market trends, and understand the relationship between property prices and macroeconomic indicators.

## 📌 Project Overview

This project analyzes **12 months of Danish residential real estate transactions**, covering **13B+ DKK ($2B+ USD)** in sales, along with **95B+ DKK ($14B+ USD)** in cumulative regional sales.

The dashboard combines property-level sales data with macroeconomic indicators to provide an interactive view of the Danish housing market.

## 🛠️ Tech Stack

* **Power BI** — Dashboard development & visualization
* **MySQL** — Data querying and processing
* **Python** — Data processing
* **Pandas & NumPy** — Data cleaning and analysis

## 📊 Dashboard Features

### Key Performance Indicators

The dashboard tracks important housing-market metrics including:

* Total sales value
* Average property price
* Price per square meter
* Number of transactions
* Regional sales performance

### 📈 Visualizations

The dashboard includes **5+ interactive visualizations**, including:

* KPI Cards
* Scatter Plots
* Funnel Charts
* Combo Charts
* Trend Analysis
* Regional comparisons

### 🔎 Interactive Filtering

Users can dynamically explore the data using slicers for:

* Area
* City
* Sales Type
* Region
* Property Type

This enables detailed drill-down into individual markets and property segments.

### 🤖 AI-Powered Analysis

Power BI's AI capabilities were used to identify:

* Key drivers influencing purchase prices
* Important variables associated with property values
* Buyer segmentation patterns
* Relationships between housing prices and market indicators

## 💡 Key Insights

The dashboard helps investigate relationships between:

**Property Prices ↔ Inflation ↔ Interest Rates ↔ Yield ↔ Region**

This allows users to identify regional differences and understand how macroeconomic conditions relate to residential property prices.

## 🚀 How to Use

1. Clone the repository.
2. Import the dataset into MySQL.
3. Run the required SQL queries.
4. Use Python/Pandas for preprocessing where required.
5. Open the `.pbix` file in Power BI Desktop.
6. Refresh the data and interact with the dashboard using the available filters.
